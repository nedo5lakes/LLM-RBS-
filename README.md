# LLM-RBS-
Profilseminar Information Systems
Das Projekt stellt einen prototypischen Ansatz für ein sprachgesteuertes Smart-Home-System dar. Ziel ist nicht die direkte Steuerung eines realen Smart Homes, sondern die konzeptionelle Demonstration, wie natürliche Sprache, Intent-Erkennung, regelbasierte Entscheidungslogik und die Ansteuerung von Aktoren miteinander kombiniert werden können.

Für einen produktiven Einsatz müsste das System um reale Geräteschnittstellen, Sensordaten, Sicherheitsmechanismen und eine robuste Integrationsarchitektur erweitert werden.

1. Spracheingabe
Benutzer gibt Text ein (akktuell kein speech to text )
→ „Mir ist kalt“
2. Verarbeitung im Sprachinterface
Intent / Kontext wird extrahiert
→ einfache Intent-/Fakt-Erkennung
→ Regel-Engine prüft Regeln
→ Textausgabe simuliert eine Aktion

Wie es funktioniert : 

mistral_prompt starten und ein Prompt eingeben , z.B "Mir ist kalt" , siehe was danach passiert :)

xps_demo kann auch getestet werden indem das Programm ausgeführt wird
